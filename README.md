# Kemarau 2026 di Kebun PCI

WebGIS pantauan kemarau dan titik api 2026 di 33 kebun Program Pertanian Cerdas Iklim (PCI), Desa Ilomata dan Suka Makmur, penyangga TN Bogani Nani Wartabone.

Disusun oleh Tim MEL Jaring Advokasi Pengelolaan Sumber Daya Alam (JAPESDA).

## Isi
- `index.html` — halaman WebGIS lengkap (data sudah tertanam di dalam file).

## Data
- Sentinel-2, MODIS, CHIRPS, ERA5-Land, NASA FIRMS, diolah di Google Earth Engine (Januari 2024 – 13 Oktober 2026).
- Poligon kebun dari tracking GPS/Avenza.
- Identitas pemilik hanya ditampilkan sebagai `id_individu`. Nama ada di MASTER_Individu (DB_Master_SSOT) dan tidak dipublikasikan.

## Memperbarui
Ganti `index.html` dengan versi baru, lalu commit. GitHub Pages memperbarui situs dalam 1–2 menit.
